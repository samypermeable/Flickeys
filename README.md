# Flickeys — setup guide

This is a small installable app: a mood-based movie & music picker for
Hollywood and Indian cinema, with live picks generated by Google's
Gemini model.

Because it calls the Gemini API directly from your phone, you need
your own API key and a place to host these files (a phone can't run a
server by itself). Both steps below are free and take a few minutes.

## 1. Get a Gemini API key

1. Go to https://aistudio.google.com/apikey and sign in with your
   Google account.
2. Click **Create API key**. It's free to create, and Gemini's free
   tier covers light personal use at no cost (Google may ask you to
   enable billing for higher usage, but casual use like this app
   typically stays within the free tier).
3. Copy the key (starts with `AIza...`). You'll paste it into the app
   itself later, not into any file.

## 2. Host the files (pick one)

You need a public URL for this folder. The easiest free option is
**GitHub Pages**:

1. Create a free GitHub account if you don't have one: https://github.com
2. Create a new repository (e.g. `flickeys`), and upload all the
   files in this folder (`index.html`, `manifest.json`,
   `service-worker.js`, and the `icons` folder) keeping the same
   structure.
3. In the repo, go to **Settings → Pages**, set the source to your
   main branch, and save.
4. GitHub will give you a URL like
   `https://yourusername.github.io/flickeys/`. That's your app's
   address.

(Netlify Drop — https://app.netlify.com/drop — is an even faster
alternative: drag this whole folder onto the page and it gives you a
URL instantly, no account needed for a quick test, though a free
account makes the URL permanent.)

## 3. Install it on your phone

**iPhone (Safari):**
1. Open your app's URL in Safari.
2. Tap the Share icon → **Add to Home Screen**.

**Android (Chrome):**
1. Open your app's URL in Chrome.
2. Tap the ⋮ menu → **Install app** (or **Add to Home screen**).

You'll get a real icon on your home screen that opens full-screen,
no browser bar.

## 4. Add your API key

The first time you open the app, it'll prompt you for your API key.
Paste the key you copied in step 1. It's saved only in the app's
local storage on your phone — it isn't sent anywhere except directly
to Google's Gemini API when you request a pick. You can change it
anytime from the settings icon (top right).

## Notes

- Every "Try another pair" and mood/region switch makes one API call.
  At typical personal use, this should comfortably stay within
  Gemini's free tier.
- Your watched history is stored locally on your phone. Uninstalling
  the app or clearing site data will erase it.
- If you ever want to share this app with someone else, don't share
  it with your key already saved in it — each person should add their
  own key.
- The app currently calls the `gemini-3.5-flash` model. If Google
  renames or retires that model later, edit the model name inside
  `index.html` (search for `generateContent`) to whatever's current.
